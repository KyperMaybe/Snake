# Змейка

«Змейка» на Python с сохранением результатов в удалённую БД MS SQL Server.

## Возможности
- Управление стрелками
- Обратный отсчёт перед стартом
- Пауза (Space / Esc)
- Ввод имени после проигрыша
- Топ-5 лучших результатов
- Изменяемый размер окна, полный экран (F11)

## Технологии
- Python 3.14
- pygame-ce
- pyodbc
- MS SQL Server

## Установка
1. `pip install -r requirements.txt`
2. Настройте подключение к БД в `config.py` (блок `DB_BASE`)
3. Запустите: `python main.py`

## Управление
- Стрелки — движение
- Space / Esc — пауза
- F11 — полный экран
- Ctrl+R — новая игра (на экране проигрыша)
- R — новая игра (после сохранения)
